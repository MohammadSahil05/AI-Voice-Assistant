# 🎙️ AI Voice Assistant

Advanced AI-powered voice assistant built using Python for automation, productivity, and smart system control.

---

## 🚀 Overview

AI Voice Assistant is a Python-based virtual assistant capable of understanding voice commands and performing various system and automation tasks. It is designed to provide a hands-free user experience similar to modern digital assistants.

---

## ✨ Features

- 🎤 Voice Recognition
- 🔊 Text-to-Speech Responses
- 🌐 Web Search and Information Retrieval
- 📂 Open Applications
- 💻 System Controls
- 📸 Screenshot Capture
- 🤖 Conversational Interaction
- ⚡ Task Automation

---

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- OpenCV
- OS & Automation Libraries
